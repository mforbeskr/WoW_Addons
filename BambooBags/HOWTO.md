# Bags - how to

- **Open/close:** your normal bag key, or `/bb`. The bank window opens by itself at the banker.
- **Sections:** Gear (ilvl 200+), Outfits, General. **Alt+click** an item to move it to the next section.
- **Search:** type in the search box; non-matching items fade.
- **Sections / Bag order:** header button switches between sorted sections and real bag order.
- **Sell junk:** button appears at vendors (greys only, never Outfits items).
- **Currencies:** tick "Show on Backpack" in the Currency tab and they show in the footer.
- **Move:** drag the window.

| Command | Does |
|---|---|
| `/bb alpha 0.6` | background opacity (0.2-1) |
| `/bb gearlevel 210` | ilvl threshold for Gear |
| `/bb resetsections` | forget all Alt+click choices |
| `/bb reset` | move windows back to default |
